# Mock Corne — ZMK config

Generated by remappr. This is a ready-to-build `zmk-config` repo with a
self-contained shield under `boards/shields/mock_corne/`.

## Build in the cloud (no toolchain)
1. Create a new GitHub repository and push these files.
2. The included workflow (`.github/workflows/build.yml`) builds on every push.
3. Open the Actions run → download the `firmware` artifact (`.uf2`).

## Build locally
```sh
west init -l config && west update
west build -s zmk/app -b YOUR_BOARD -- -DSHIELD=mock_corne -DZMK_CONFIG="$(pwd)/config" -DZMK_EXTRA_MODULES="$(pwd)"
```

## Notes
- Set `board` in `build.yaml` to your actual controller (currently `YOUR_BOARD`).
- `boards/shields/mock_corne/mock_corne.overlay` holds the kscan + matrix-transform +
  physical-layout; `mock_corne.keymap` the bindings; `Kconfig.shield` /
  `Kconfig.defconfig` register the shield. `config/mock_corne.conf` holds the Kconfig flags.
- Builds against ZMK `v0.3` (`config/west.yml` and the workflow).
  To move, change both refs; boards differ between releases and `main`.
- Re-check the matrix-transform `RC()` map against your real kscan wiring —
  remappr derives it from physical key position, not the electrical matrix.
